WELDIORE WORDPRESS THEME — INSTALLATION & HANDOVER
Version 1.1.0

INCLUDED
- Responsive custom WordPress theme for a premium B2B leather and fashion bag manufacturer.
- Custom Product post type and product category/material taxonomies.
- Product specification fields in WordPress admin.
- Quote enquiry form with server-side validation, nonce protection, honeypot, lead storage and admin-email notification.
- Quote Enquiries admin panel with status field.
- Homepage, product archive, product detail, category, general page, blog and 404 templates.
- English-language responsive layouts and basic SEO/performance foundations.

INSTALLATION
1. Back up the existing WordPress site and database.
2. In WordPress Admin, go to Appearance > Themes > Add New Theme > Upload Theme.
3. Upload weldiore-theme.zip and activate Weldiore.
4. Go to Settings > Permalinks and click Save Changes once.
5. Confirm the automatically-created pages exist: About Weldiore, Custom Manufacturing, Manufacturing & Quality, Industries Served, Request a Quote, Contact Us and Insights.
6. Set the site homepage under Settings > Reading to a static page titled Home. If Home does not exist, create a page titled Home; the front-page.php template will be used for the site front page.
7. The theme creates a Home page; set it as the static homepage under Settings > Reading. Add products under Products > Add New Product. Set featured image, excerpt, description and product category; fill the Product Specifications fields.
8. Add company-approved content and actual product photography. Replace all illustrative external photo URLs and placeholder text before public launch.
9. Set a valid WordPress Administration Email under Settings > General. Configure SMTP through a trusted mail provider/plugin and test delivery; wp_mail depends on hosting/mail configuration.
10. Submit a test enquiry and confirm it appears under Quote Enquiries and the notification reaches the sales inbox.
11. Configure SEO plugin, GA4, Search Console, privacy policy and backup/security plugins as required.

IMPORTANT
- This theme is a deployable starting build, not a deployment to the client's live hosting. It has not been tested against the client's specific WordPress installation, PHP version, plugins or mail provider.
- Includes 17 catalogue reference products populated from the two client-supplied PDFs (12 LC-series styles and 5 laptop-bag catalogue references). Images are copied into the theme and imported to the WordPress media library when the theme is activated.
- The Arno source catalogue states MOQ 100 pieces on the relevant pages; the seeded product entries mark this as subject to confirmation. Verify ownership/permission to publish all supplied catalogue images before public launch.
- Some homepage editorial/workshop imagery may remain external stock imagery; replace with company-approved factory photography before launch.
- Company contact information, factory details, certifications, manufacturing capacity and other business claims must be verified and supplied by the client.
- WordPress core, theme and plugins must be kept updated. Use HTTPS and scheduled backups.
- Quote enquiries are stored as private WordPress posts. Limit admin access to trusted users and define a retention policy for personal data.
- Product category pages use WordPress taxonomy archives. Add category terms in Products > Product Categories.
- No payment gateway, shopping cart, customer portal, CRM integration, WhatsApp API or multilingual feature is included.
